# Original CrowdSmarter consultancy website

This directory preserves the standalone CrowdSmarter website that existed
before the full SaaS application was added to this repository.

It is retained for historical reference and possible reuse of validated
consultancy positioning, founder content, visual design, and service concepts.

It is not the entry point for the current React application.
The current frontend entry point is `frontend/index.html`.

Before reusing public claims, pricing, credentials, external forms, or personal
information, review and validate them.
