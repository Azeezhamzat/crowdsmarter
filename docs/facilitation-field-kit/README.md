# CrowdSmarter facilitation field kit

Use this kit when a real facilitated decision or later field-evidence
opportunity exists. It is not the active outreach plan. Current development is
guided by the internet-research method in `docs/research/`.

The kit is a practice aid, not a script that replaces judgement. Keep the
platform out of the opening conversation unless a shared record would
genuinely improve the process.

## Suggested sequence

1. For hybrid delivery, begin with `hybrid-session-capture-pack.md` to define
   influence, channels, capture, synthesis, response, and review.
2. If later discovery conversations become appropriate, use
   `three-conversation-sprint.md` to select varied viewpoints, invite people,
   and run the first evidence review.
3. Use `discovery-conversation-record.md` during or immediately after a
   discovery conversation.
4. Complete `engagement-fit-assessment.md` before proposing an engagement.
5. If a bounded pilot is appropriate, agree
   `pilot-learning-agreement.md` with the decision authority.
6. Review the pilot with `pilot-scorecard.md`, using evidence from both the
   authority and participants.
7. Record any change to the offer or workflow in
   `validation-change-log.md`.

## Working rules

- Ask about a recent real decision before explaining CrowdSmarter.
- Separate what the participant said from the facilitator's interpretation.
- Mark quotations as verbatim or paraphrased. Do not attribute a quotation
  without permission.
- Record evidence against a hypothesis as carefully as evidence supporting it.
- Collect only the personal data needed for the agreed follow-up.
- Agree confidentiality, retention, deletion, accessibility, and safeguarding
  before a pilot begins.
- Treat a decision not to use the platform as a valid finding.

These templates may be copied into the client's agreed working environment.
Do not place confidential client material in the public source repository.
