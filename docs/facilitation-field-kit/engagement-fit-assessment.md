# Engagement fit assessment

Complete this assessment after discovery and before proposing a facilitated
engagement. A poor fit should lead to an honest decline, referral, or smaller
piece of work.

## Conditions that must be credible

| Condition | Yes | No | Unclear | Evidence or action needed |
|---|---|---|---|---|
| There is a real decision that has not already been settled. |  |  |  |  |
| A named person or body holds final authority. |  |  |  |  |
| Other people hold relevant knowledge, experience, or legitimate interests. |  |  |  |  |
| Participation can influence the process or record honestly. |  |  |  |  |
| There is enough time for meaningful involvement. |  |  |  |  |
| Confidentiality, safeguarding, accessibility, and conflict risks can be managed. |  |  |  |  |
| The client will own follow-through after the facilitated work. |  |  |  |  |

Do not proceed to a participatory pilot when the decision is already fixed,
participation would be performative, authority is deliberately concealed, or
material safeguarding and confidentiality risks cannot be managed.
