# Hybrid session capture pack

Use this pack when participation happens through a mixture of in-person,
phone, paper, partner-supported, or digital channels. Participants do not need
platform accounts. The facilitator records only what the agreed decision
process needs and explains how each contribution will be used.

This is a structured working record, not a transcript and not evidence that
every person agrees with the synthesis.

## 1. Decision and influence frame

| Field                                 | Record |
| ------------------------------------- | ------ |
| Decision or question                  |        |
| Why it matters now                    |        |
| Named decision authority              |        |
| What participants can influence       |        |
| What is fixed or outside scope        |        |
| How input will be considered          |        |
| When and how a response will be given |        |
| Facilitator and record owner          |        |

Stop if there is no honest answer to what participants can influence. An
information session may still be useful, but it should not be described as a
participatory decision process.

## 2. Access and channel plan

| Participant group or perspective | Why it matters | Preferred channel | Access or language support | Recruitment or representation gap | Owner |
| -------------------------------- | -------------- | ----------------- | -------------------------- | --------------------------------- | ----- |
|                                  |                |                   |                            |                                   |       |
|                                  |                |                   |                            |                                   |       |
|                                  |                |                   |                            |                                   |       |

Check before opening participation:

- small-screen and low-bandwidth access;
- venue, travel, timing, childcare, and disability access;
- literacy and language support;
- a private route for sensitive contributions;
- whether anonymity, confidentiality, or attribution is promised;
- how paper, phone, and partner-gathered input will enter the same record;
- consent, safeguarding, retention, and deletion arrangements.

## 3. Contribution capture

Create one entry per distinct contribution. Do not combine disagreement during
capture.

| Field                                                                  | Record |
| ---------------------------------------------------------------------- | ------ |
| Capture reference                                                      |        |
| Date and channel                                                       |        |
| Attributed, confidential, or anonymous                                 |        |
| Participant group or perspective                                       |        |
| Contribution in the participant's words or a clearly marked paraphrase |        |
| Evidence, experience, assumption, concern, option, or question         |        |
| Related decision criterion or option                                   |        |
| Permission to quote or attribute                                       |        |
| Follow-up or verification needed                                       |        |

Do not infer demographic characteristics. Collect them only when they have a
defined, proportionate purpose and an appropriate basis.

A human reviews the synthesis against the source records. AI may assist only
when the agreed privacy and confidentiality conditions allow it; its output
must never replace source material or human approval.

## 5. Authority response and feedback loop

| Field                                         | Record |
| --------------------------------------------- | ------ |
| What participants contributed                 |        |
| What changed because of the input             |        |
| What did not change, and why                  |        |
| Decision and rationale                        |        |
| Conditions, dissent, and unresolved questions |        |
| Action owners and dates                       |        |
| Review or appeal route, if any                |        |
| Publication and participant-response channel  |        |
| Response date and responsible person          |        |

The decision authority approves this response. A facilitator may draft it but
must not silently make the decision or imply consensus.

## 6. Process review

Rate each item as demonstrated, partly demonstrated, not demonstrated, or not
applicable, and attach evidence:

- the question and influence boundary were understood;
- people could use a workable channel;
- relevant perspectives were represented or their absence was disclosed;
- contributions were captured without erasing material disagreement;
- the decision authority considered the record;
- the response explained what changed and what did not;
- actions and review points have named owners;
- personal data was handled as agreed;
- the platform reduced reconstruction work without becoming a participation
  barrier.

Record one change to the next process, its owner, and the evidence that would
show whether the change helped.
