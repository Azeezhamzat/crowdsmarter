# Phase 9 quality gate

Phase 9 is complete only when:

- the public site, sign-in screen, personal dashboard, organisation home, portfolio, and decision workspace share one coherent visual language;
- keyboard quick navigation works without changing business data;
- mobile navigation can be opened and dismissed with keyboard and pointer input;
- reduced-motion preferences disable non-essential transitions;
- My Work and portfolio filters preserve all existing decision links and next-action information;
- no business-domain API, permission, or lifecycle rule is weakened;
- frontend type checking, component tests, and the production build pass in Docker;
- existing backend checks and migrations remain clean;
- the archive includes no local configuration, database dumps, credentials, or dependency directories;
- the upgrade can restore Phase 8 source automatically if validation fails.
