# ADR 0023 — Governed scenario sets grounded in critical uncertainties

## Status

Accepted for Phase 13.

## Context

Phase 12 provides traceable signals, drivers, critical uncertainties, systems relationships, and strategic implications. Scenario construction must build on those records without creating a separate foresight universe or presenting speculative narratives as forecasts.

## Decision

A scenario set belongs to one foresight canvas and uses two different active drivers explicitly classified as critical uncertainties. The set records human-readable endpoint labels and may link to one decision in the same organisation. It supports one scenario world per 2×2 quadrant.

Each scenario is a human-authored record with explicit assumptions, opportunities, threats, driver states, reviews, and links to existing strategic implications. Scenario construction does not alter the canvas drivers or decision lifecycle.

## Consequences

- scenario provenance remains traceable to Phase 11 signals and Phase 12 drivers;
- duplicate or contradictory quadrant records are prevented structurally;
- scenario narratives can evolve without masquerading as forecasts;
- later forecasting can attach calibrated probabilities without redesigning the scenario domain;
- tenant and canvas boundaries remain enforceable in services and database constraints.
